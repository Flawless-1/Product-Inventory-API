# Product Inventory API 🚀

A RESTful backend service built with Node.js, Express, and PostgreSQL to manage product inventory.

---

## 🛠️ Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** PostgreSQL (Neon Cloud DB)
* **Environment Management:** `dotenv`

---
